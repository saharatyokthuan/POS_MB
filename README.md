# 🛒 Quick POS — ระบบขายหน้าร้าน (Point of Sale) บนเบราว์เซอร์

เว็บแอป POS สำหรับร้านค้าขนาดเล็ก ออกแบบสำหรับมือถือ (แถบเมนูด้านล่าง) ทำงานฝั่งเบราว์เซอร์ล้วน ไม่มี backend เก็บข้อมูลในเครื่องผ่าน `localStorage`

---

## ✨ ฟีเจอร์หลัก

| หมวด | ความสามารถ |
|:---|:---|
| 🛒 **ขายสินค้า (POS)** | ค้นหาด้วยชื่อ/รหัสสินค้า/บาร์โค้ด (กด Enter เพื่อเพิ่มรายการแรกที่พบ), กรองตามหมวดหมู่, ตะกร้าสินค้า, ส่วนลด (บาท หรือ %), เลขที่บิลรันอัตโนมัติ (`B00001`) |
| 💵 **ชำระเงิน** | เงินสด (keypad + ปุ่มรับเงินด่วน + คำนวณเงินทอน), โอน, บัตร, ขายเชื่อ, พิมพ์ใบเสร็จผ่าน `window.print()` |
| ⏸️ **พักบิล** | พักตะกร้าปัจจุบัน เรียกกลับมาขายต่อ หรือลบบิลที่พักไว้ |
| 📷 **สแกนบาร์โค้ด** | อ่านบาร์โค้ดจากกล้องสดหรือรูปถ่าย ผ่าน `BarcodeDetector` API (ต้องใช้เบราว์เซอร์ที่รองรับ) ทั้งในหน้าขายและฟอร์มสินค้า |
| 📦 **สินค้า / สต๊อก** | เพิ่ม/แก้ไข/ลบสินค้า (รหัสสินค้า, บาร์โค้ด, ชื่อ, ราคาขาย, ราคาทุน, สต๊อก, สต๊อกขั้นต่ำ, วันหมดอายุ), กรองตามหมวด/สถานะสต๊อก, ปรับสต๊อกแบบกลุ่ม, ตัดสต๊อกอัตโนมัติเมื่อขาย |
| 🏷️ **หมวดหมู่อัตโนมัติ** | จับคู่หมวดหมู่จากตัวเลขนำหน้ารหัสสินค้า (`OFFICIAL_CATEGORY_MAPPING` — ตารางรหัสหมวดหมู่ทางการที่ล็อกไว้) และเพิ่ม mapping ของตัวเองได้ |
| 🚚 **สั่งซื้อ (Purchase)** | บันทึกการซื้อสินค้าเข้า และรายงานการสั่งซื้อ |
| 💳 **ลูกหนี้** | ขายเชื่อจากตะกร้า, เพิ่มลูกหนี้เอง, บันทึกการรับชำระ, ดูยอดค้างและจำนวนบิลค้าง |
| 📊 **รายงาน** | แท็บยอดขาย (ยอดรวม กำไร จำนวนบิล เฉลี่ยต่อบิล + กราฟ), สต๊อก, รายจ่าย, เปรียบเทียบสองช่วงเวลา (เดือนต่อเดือน / สัปดาห์ต่อสัปดาห์) |
| 📥📤 **Excel / สำรองข้อมูล** | นำเข้าสินค้าจาก `.xlsx`/`.xls`, อัปเดตเฉพาะชื่อ+หมวดหมู่จาก Excel, ส่งออกสินค้า/ยอดขาย/สต๊อก/สั่งซื้อ/รายจ่ายเป็น `.xlsx` (SheetJS), สำรอง/กู้คืนข้อมูลทั้งหมดเป็นไฟล์ `.json` |
| ⚙️ **ตั้งค่า** | ชื่อร้าน ที่อยู่ เบอร์โทร Tax ID, เกณฑ์แจ้งเตือนสต๊อกต่ำ (ค่าเริ่มต้น 5), แจ้งเตือนก่อนหมดอายุ (ค่าเริ่มต้น 30 วัน), VAT 7% (ไม่คิด / รวมแล้ว / บวกเพิ่ม), ล้างข้อมูลทั้งหมด |
| 🔔 **แจ้งเตือน** | ป้ายตัวเลขที่เมนูสินค้าเมื่อมีสินค้าสต๊อกต่ำหรือใกล้หมดอายุ |

> ⚠️ **หมายเหตุสถานะปัจจุบันของ repo:** โค้ดใน `script-pos.js` เขียนแบบหลายหน้า — ปุ่มเมนูจะไปที่ `products.html`, `purchase.html`, `debt.html`, `reports.html`, `more.html` (ดู `showPage()`) แต่ใน repo นี้มีเพียง `index.html` ซึ่งมี markup ของทุกหน้าอยู่ในไฟล์เดียว และ JS เริ่มต้นเฉพาะหน้า `pos` เมื่อไม่มี `data-page` บน `<body>` ดังนั้นหน้าที่ใช้งานได้ทันทีจาก `index.html` คือหน้าขายสินค้า (POS) ส่วนหน้าอื่นต้องมีไฟล์ `.html` ที่ตรงกับชื่อเหล่านั้นจึงจะเข้าถึงได้

## 🚀 วิธีใช้งาน

ไม่ต้องติดตั้งหรือ build — เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที (ต้องต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีจาก CDN) หรือรันผ่าน local server:

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

ถ้าเป็นการเปิดครั้งแรกและยังไม่มีสินค้า แอปจะใส่สินค้าตัวอย่าง 4 รายการให้ (`seedDemoData()`) เพื่อทดลองขาย

### ข้อมูลเก็บที่ไหน
ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์ โดยใช้คีย์ขึ้นต้นด้วย `qpos_` (เช่น `qpos_products`, `qpos_sales`, `qpos_debts`) จึงผูกกับเบราว์เซอร์/เครื่องนั้น ๆ และอาจหายหากล้างข้อมูลเบราว์เซอร์ — ควรใช้ปุ่มสำรองข้อมูล (ไฟล์ `qpos-backup-YYYY-MM-DD.json`) เป็นระยะ

### คอลัมน์ในไฟล์ Excel สำหรับนำเข้าสินค้า
อ่านจากชีตแรก รองรับหัวคอลัมน์ (ไทย/อังกฤษ):

| ข้อมูล | หัวคอลัมน์ที่รองรับ |
|:---|:---|
| รหัสสินค้า | `Master Product ID`, `รหัสสินค้า`, `Product ID` |
| บาร์โค้ด (จำเป็น) | `บาร์โค้ด`, `Barcode`, `barcode` |
| ชื่อสินค้า (จำเป็น) | `ชื่อสินค้า`, `ชื่อสินค้า EN` |
| หมวดหมู่ | `หมวดหมู่`, `Category` |
| ราคาขาย | `ราคาขาย`, `Price`, `ราคา` |
| ราคาทุน | `ราคาทุน`, `Cost`, `ต้นทุน` |
| สต๊อก | `สต๊อก`, `Stock`, `stock` |
| วันที่ | `วันที่เริ่มจำหน่าย`, `วันหมดอายุ` (บันทึกเป็นวันหมดอายุ) |

สินค้าที่รหัสหรือบาร์โค้ดซ้ำกับของเดิมจะถูกอัปเดต ส่วนที่ไม่มีจะถูกเพิ่มใหม่

- **[SheetJS (xlsx) 0.18.5](https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js)** — นำเข้า/ส่งออก Excel (โหลดจาก cdnjs)

- **Google Fonts** — Inter และ JetBrains Mono
- **Web APIs** — `localStorage`, `BarcodeDetector`, `navigator.mediaDevices.getUserMedia`, `FileReader`, `window.print`
